## 검수 방법

1차와 같이 **경로 단위**로 본다. 검수표 한 줄이 경로 하나다.

1. `originals.md`에서 정책 원문을 읽는다.
2. 검수표의 경로 줄마다 적는다.
   - **① 원문에 있는 경로인가**: 원문에 없는 대상을 만들어 냈으면 X
   - **② 조건이 맞는가**: 숫자·범위·포함/제외가 원문과 다르거나, 원문에 없는 조건이 들어갔으면 X
3. 정책마다 있는 `빠진 경로가 있는가` 줄에 **③ 빠진 경로·조건**을 적는다.
4. X를 준 곳은 `수정 의견`에 고칠 내용을 적고, `검수자`에 이름을 적는다.

`자동 점검` 열은 스크립트가 미리 확인한 결과다(입력 항목이 진단에 있는지, 근거 구절이 원문에 그대로 있는지). 지금은 모두 OK다.

### 판단 기준 (1차와 같음)

- **비교 조건**에는 프론트 입력으로 판정할 수 있는 것만 넣는다. 나머지는 **확인 사항**으로 둔다.
- 입력이 원문보다 거칠면(예: 원문은 '중증 장애인', 입력은 '장애 여부'), 꼭 필요한 조건(등록 장애인)만 비교 조건으로 두고 나머지(중증일 것)는 확인 사항으로 둔다. **신청 가능한 사람을 '불가'로 판정하지 않기 위해서다.**
- 가구원 수·맞벌이 여부에 따라 기준이 달라지면 가장 느슨한 기준만 비교 조건으로 두고, 정확한 표는 확인 사항에 적는다.
- 가점·우선선발은 `우대`로 두고 판정에 쓰지 않는다.

## 특히 봐 줬으면 하는 곳

초안을 쓰면서 판단이 갈린 곳이다. 검수표 `수정 의견`에 결론을 적어 주면 된다.

1. **행복주택 청년 경로의 소득**: 원문이 "세대소득(세대주가 아닌 세대원은 본인소득)"이라, 부모와 사는 청년은 가구소득으로 비교하면 잘못 '불가'가 될 수 있다. 그래서 비교 조건에서 빼고 확인 사항으로 뒀다. 맞는가?
2. **행복주택 주거급여 경로의 '중위소득 45% 이하'**: 현행 주거급여 기준(48%)과 달라 원문이 오래된 기준일 수 있다. 그래서 비교 조건으로 넣지 않고 확인 사항으로 뒀다.
3. **국민취업지원제도 Ⅱ유형 일반**: 원문에 나이 기준이 없어 넣지 않았다(실제 사업은 15~69세).
4. **햇살론youth '미취업 청년'**: 아르바이트도 미취업으로 볼지. 지금은 포함했다(잘못된 '불가'를 피하는 쪽).
5. **햇살론youth '사회초년생'**: 입력의 '재직'이 중소기업인지 알 수 없어 '재직'과 '중소기업 재직'을 모두 넣었다.
6. **가스요금 다자녀**: 원문은 손자녀·위탁아동도 포함하지만 입력은 자녀 수뿐이다. 청년 이용자에게는 드문 경우라 자녀 3명 이상으로 비교했다.
7. **대학생 근로장학금 소득(학자금 지원 9구간)**: 학자금 구간은 부모(기혼은 배우자) 포함 소득이라 입력 가구소득과 다르다. 그래서 확인 사항으로 뒀다.

## 판정 결과 미리보기

테스트 프로필 5개로 초안을 돌려 본 결과, 신청 가능한 사람을 '불가'로 판정한 경우는 없었다.
다만 판정기 쪽에서 고칠 점이 하나 보였다.

- **경로 선택**: 판정기는 '충족한 조건이 가장 많은 경로'를 대표로 보여준다. 그래서 대학생 프로필이 행복주택에서 '대학생' 경로가 아닌 '창업인·지역전략산업' 경로로 표시됐다. 창업인 경로는 소득·자산 조건이 많아서 충족 개수가 더 많기 때문이다. 판정 결과(가능)는 맞지만 경로 이름이 어색하다. 확인 사항에만 기대는 경로(창업·산업단지·중소기업)의 우선순위를 낮출지 백엔드 담당자와 정해야 한다.

## 검수가 끝나면

1. 검수 의견대로 `eligibility_paths_batch2_draft.json`을 고친다.
2. 고친 정책을 `eligibility_paths_reviewed.json`의 `policies`에 옮긴다.
3. 시드를 다시 만들고 DB에 넣는다.

```bash
cd backend
python scripts/build_eligibility_paths.py && python scripts/load_eligibility_paths.py
```

검수표는 초안을 고친 뒤 다시 만들 수 있다. 3차부터도 같은 스크립트를 쓴다.

```bash
cd backend
python scripts/make_review_sheet.py data/eligibility_paths_batch2_draft.json ../docs/eligibility-paths/batch-2
```
