4건 모두 WLF00006224의 아래 경로에 대한 `비교 조건 없음 → 이 정책은 '불가'가 되지 않음` 안내다. 스크립트는 안내와 오류를 같은 문제 수에 포함한다. 이를 자동 점검 0건으로 보고하지 않는다.

- `수급권자`: 현재 수급 중이라는 본인 입력과 법상 수급받을 권리가 있다는 의미를 동일시하지 않았다.
- `학교`, `사회복지시설`, `조례시설`: 원문에 실제 존재하지만 개인 프로필로 비교할 항목이 없다.

위 경로를 조건 없이 보존한 결과 해당 정책은 입력만으로 확정 불가가 되지 않는다. 시설 경로를 개인용 진단에서 어떻게 안내할지는 사람이 검토할 사항이다. 경고를 없애기 위해 원문의 대상을 삭제하거나 가상의 입력 조건을 넣지 않았다.

## 작성 시 판단을 보류한 부분

1. **엄격한 소득 하한:** 자립자금대여는 `50% 초과 100% 이하`다. 허용 연산자에 `gt`가 없고 현재 입력 변환은 중위소득 비율을 소수 첫째 자리로 반올림한다. `gte 51` 등으로 임의 변환하면 대상자가 제외될 수 있어 100% 이하만 비교하고, 50% 초과 하한은 확인 사항으로 명시했다. 하한 표현의 적절성과 2025년 금액 예시/현재 연도 기준의 차이는 승인 전에 검토한다.
2. **다른 상품 안내:** 같은 원문의 미소금융재단 장애인대출 안내는 다른 상품이다. 이를 이 정책의 50% 이하 대안 경로로 추가하지 않았다. 안내 원문은 대조 문서에 보존된다.
3. **가구 소득과 소득인정액:** 청소년특별지원은 `가구의 소득`이라고만 쓰여 있다. 이를 가구 소득인정액 입력과 같다고 가정하지 않았다. 중위소득 100%와 실제 생계·주거를 같이하는 부모라는 기준을 확인 사항에 보존했다.
4. **가구 자격과 본인 자격:** 생리용품 지원은 가구 기준이다. 가구 수급자 정보 자체는 별도로 입력받을 수 있으나 현재 경로 엔진의 허용 필드에 같은 의미로 제공되지 않는다. 본인 수급·차상위·한부모 입력만으로 가구 해당자를 제외하지 않도록 각 대상의 확인 사항으로 남겼다. 승인 전 필드 의미를 재확인한다.
5. **학교 밖·훈련생:** 학교 밖 청소년을 일반 `재학 여부`의 단순 반대로, 직업능력개발훈련기관 훈련생을 일반 학교 재학생으로 바꾸지 않았다.
6. **사업 전체와 세부 지원:** 직업재활지원 기본 대상을 유지하고, 훈련 필요성·수당의 실업급여 자격·80% 출석 기준 및 훈련준비금/자격 취득수당 예외는 해당 경로에서만 안내한다. 기본 경로와 세부 경로의 구분이 원문 취지에 맞는지 검토한다.
7. **신청 시점과 사업 시작 시점:** 장애인일자리의 근로종료 예정 예외를 별도 경로로 남겼다. 현재 미취업이라는 비교만 모든 경로에 강제하지 않았다. 재직기간·종료일·사업자등록·반복참여 제한 등은 입력만으로 확인할 수 없어 원문 기준을 확인 사항에 보존했다.
8. **가구·대상 범위가 불명확한 단서:** 청소년특별지원의 다른 제도 동일지원 제한을 공통 확인 사항으로 두었으나, 원문상 마지막 대상 뒤에 붙은 단서이므로 적용 범위는 사람 검수에서 확인한다.

## 사람 검수 진행

```powershell
cd backend
.\.venv\Scripts\python.exe -B scripts/review_server.py data/eligibility_paths_batch3_draft.json
```

`http://localhost:8765`에서 각 비교 조건·확인 사항·우대를 채점하고, 누락 조건을 기록한다. 이 명령은 사람이 검수를 시작할 때 실행하는 예시이며 초안 작성 중에는 실행하지 않았다.

**검수 종료와 별도 승인 전에는** `merge_reviewed.py`, `build_eligibility_paths.py`, `load_eligibility_paths.py`를 실행하지 않는다. `eligibility_paths_reviewed.json`과 `eligibility_paths.json`을 직접 고치지 않는다. 이번 단계에서는 전체 테스트나 프로필별 판정 검증도 수행하지 않았으며, 자동 근거 검사 통과를 사람 검수 완료로 취급하지 않는다.
